# 解答

老師用的參考解答，都是網站的「作品檔」：學習目標先選對（C++ 的解答要選 C++，或網址加 `&target=cpp`），打開那一題，右上角「檔案」→「匯入作品資料」選這裡的 `.json`，就會看到變數表、流程圖，第四步可以直接跑測資。在別題匯入也可以，網站會問要不要切換到那一題。

每一題的解答都在網站上跑過題目全部的測資（輸出跟預期一樣），「看程式」轉出來的程式也看過。流程圖是用網站「看程式 → 編輯」套用回流程圖時的自動排版畫的，太寬的可以用畫布右下角的 －／＋ 縮小看。

## 資料夾

```
solutions/
  課程代號/            課程（跟網址 ?course= 一樣，例如 life、adv）
    學習目標/          cpp、python、scratch、blockly
      序號_題目名稱.json  序號是題目在課程裡的順序
```

其他課程、其他學習目標的解答照這個方式放。表格裡的「代號」是網址 ?w=課程&h=題目 的 h。
